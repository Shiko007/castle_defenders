# 🤖 AI Asset Generation Prompts for Castle Defenders (2D Top-Down)

## 📐 IMPORTANT NOTES FOR ALL PROMPTS

**For DALL-E/ChatGPT Image Generation:**
- Request **transparent background** in every prompt
- Specify **top-down view** (bird's eye view) for 2D game
- Request **game asset style** or **pixel art style**
- Ask for **simple, clean designs** (AI struggles with complexity)
- Generate at **1024x1024** then crop/resize in image editor

**Post-Processing:**
- Use **remove.bg** to clean up backgrounds if needed
- Resize in image editor to specifications below
- Save as PNG with transparency

## 💡 PRO TIPS FOR AI GENERATION

### **If AI Generation Doesn't Work Well:**

1. **Try multiple variations** - Generate 3-4 versions, pick the best
2. **Simplify the prompt** - Remove details if too complex
3. **Use "pixel art" style** - AI is better at pixel art than realistic sprites
4. **Request "game asset style"** - This helps AI understand context
5. **Emphasize "top-down view"** - Critical for 2D game consistency

### **Alternative Styles to Try:**

**Pixel Art Style Prompt Addition:**
```
Add to any prompt: "in pixel art style, 64x64 pixels, retro gaming aesthetic, limited color palette"
```

**Cartoon Style Prompt Addition:**
```
Add to any prompt: "in cute cartoon style, bold outlines, vibrant colors, mobile game aesthetic"
```

**Minimalist Style Prompt Addition:**
```
Add to any prompt: "minimalist design, flat colors, simple shapes, modern game art style"
```

## 🆘 TROUBLESHOOTING

**Problem:** AI generates side view instead of top-down
**Solution:** Emphasize "bird's eye view" and "viewed from directly above" even more

**Problem:** Background isn't transparent
**Solution:** Use remove.bg website or specify "isolated on white background" then remove in editor

**Problem:** Asset is too detailed/complex
**Solution:** Simplify prompt, request "simple game asset" or "pixel art style"

**Problem:** Colors don't match
**Solution:** Specify color palette in prompt: "using colors: green, brown, gray"
